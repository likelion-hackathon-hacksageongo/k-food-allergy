# 데이터 수집 가이드 (데이터팀용)

AI 분석 모듈이 기대하는 식당/메뉴 데이터 형식입니다.
이 형식에 맞춰 수집하면 바로 분석에 투입할 수 있습니다.

---

## 1. 식당 데이터 (`restaurants.json`)

```json
[
  {
    "id": 1,
    "name": "Hongdae Hansotbap",
    "name_ko": "홍대 한솥밥",
    "category": "한식",
    "address": "서울 마포구 와우산로 123",
    "latitude": 37.5563,
    "longitude": 126.9220,
    "menu_items": [
      {
        "id": 101,
        "name": "Doenjang Jjigae",
        "name_ko": "된장찌개",
        "description": "된장, 두부, 호박, 감자, 청양고추",
        "ingredients": ["된장", "두부", "호박", "감자", "청양고추", "멸치육수"]
      },
      {
        "id": 102,
        "name": "Kimchi Jjigae",
        "name_ko": "김치찌개",
        "description": "김치, 돼지고기, 두부, 대파",
        "ingredients": ["김치", "돼지고기", "두부", "대파", "고춧가루"]
      }
    ]
  }
]
```

---

## 2. 필드 설명

### 식당 (Restaurant)

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `id` | int | ✅ | 고유 ID (1부터 순번) |
| `name` | string | ✅ | 식당명 (영어/로마자) |
| `name_ko` | string | ✅ | 식당명 (한국어) |
| `category` | string | ✅ | 음식 카테고리 (아래 목록 참고) |
| `address` | string | ✅ | 주소 |
| `latitude` | float | ✅ | 위도 (카카오맵에서 확인) |
| `longitude` | float | ✅ | 경도 |
| `menu_items` | array | ✅ | 메뉴 목록 (최소 1개) |

### 메뉴 (MenuItem)

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `id` | int | ✅ | 고유 ID (식당 ID × 100 + 순번 권장) |
| `name` | string | ✅ | 메뉴명 (영어/로마자) |
| `name_ko` | string | ✅ | 메뉴명 (한국어) |
| `description` | string | ⬜ | 간단한 설명 또는 주요 재료 나열 |
| `ingredients` | array[string] | ⬜ | 알려진 재료 목록 (한국어) |

---

## 3. 카테고리 목록

수집 시 아래 중 하나를 선택하세요:

- `한식` — 일반 한식 (찌개, 구이, 밥류)
- `분식` — 떡볶이, 김밥, 라면, 만두
- `국밥` — 국밥, 설렁탕, 해장국
- `치킨` — 치킨 전문점
- `고기` — 삼겹살, 갈비, 소고기 전문
- `해산물` — 회, 해물탕, 조개구이
- `죽/면` — 죽, 칼국수, 냉면
- `카페/디저트` — 카페, 빵집 (알레르기 위험 높음)
- `일식` — 일식당 (초밥, 라멘)
- `중식` — 중식당 (짜장면, 탕수육)

## 4. 재료(ingredients) 작성 가이드

### 핵심 원칙
- **보이는 재료 + 숨은 재료** 모두 기입
- 양념, 육수, 소스도 가능한 한 포함
- 확실하지 않으면 비워두기 (AI가 조리 패턴으로 추정)

### 숨은 재료 체크리스트 (한식 특화)

| 음식 유형 | 확인할 숨은 재료 |
|-----------|-----------------|
| 찌개/국물 | 멸치육수, 다시마, 새우젓, 조개육수 |
| 김치 관련 | 새우젓, 멸치액젓, 생젓갈 |
| 양념/소스 | 간장(대두), 된장(대두), 고추장(밀+대두), 참기름 |
| 전/부침개 | 밀가루, 달걀 |
| 밥류 | 참기름, 달걀, 김 |
| 나물 | 참기름, 들기름, 깨 |
| 고기 양념 | 간장, 배, 설탕, 참기름 |

### 예시 — 된장찌개
```
❌ 나쁜 예: ["된장", "두부", "호박"]
✅ 좋은 예: ["된장", "두부", "호박", "감자", "멸치육수", "다시마", "청양고추", "대파"]
```

## 5. 수집 방법 팁

### 메뉴판 사진
- 가게 앞 메뉴판 사진 → 메뉴명 + 가격 확보
- 배달앱(배달의민족, 요기요) 메뉴 참고 가능

### 재료 파악
- 메뉴판에 재료 표기가 있으면 그대로 기입
- 없으면 일반적인 조리법 기준으로 추정 기입
- 확인 불가 시 `ingredients: []` (빈 배열)로 두기 — AI가 카테고리 + 메뉴명으로 추정

### 좌표 확인
- 카카오맵에서 식당 검색 → 주소 클릭 → URL에서 좌표 확인
- 또는 구글맵에서 우클릭 → 좌표 복사

```
data/
```

## 7. 알레르겐 16종 참고표

수집 시 아래 알레르겐이 포함된 재료가 있는지 특히 주의하세요:

| 알레르겐 | 한식에서 흔한 원인 재료 |
|---------|----------------------|
| 대두 (soy) | 된장, 간장, 고추장, 두부, 콩나물 |
| 밀 (wheat) | 밀가루, 고추장, 국수, 만두피, 부침개 |
| 갑각류 (shellfish) | 새우, 게, 새우젓, 크래미 |
| 달걀 (egg) | 계란말이, 전, 비빔밥 토핑 |
| 생선 (fish) | 멸치육수, 멸치, 고등어, 생선구이 |
| 유제품 (dairy) | 치즈, 크림소스 (한식에는 드묾) |
| 땅콩 (peanut) | 땅콩소스, 잡채 (드묾) |
| 견과류 (nuts) | 잣, 호두, 깨 |
| 조개류 (mollusk) | 조개, 오징어, 전복, 굴 |
| 돼지고기 (pork) | 삼겹살, 김치찌개 고기, 만두소 |
| 쇠고기 (beef) | 불고기, 갈비탕, 육수 |
| 닭고기 (chicken) | 삼계탕, 치킨, 닭볶음탕 |
| 복숭아 (peach) | 음료, 디저트 (드묾) |
| 아황산류 (sulfites) | 와인, 식초, 건과일 |
| 메밀 (buckwheat) | 냉면, 메밀전 |
| 토마토 (tomato) | 소스류 (한식에는 드묾) |

## 8. 목표 수량

MVP 기준:
- **홍대 일대 식당: 20~30곳**
- **식당당 메뉴: 3~10개** (인기 메뉴 위주)
- 총 메뉴 수: 100~200개

우선순위:
1. 한식 전문점 (찌개, 구이, 밥)
2. 분식/국밥
3. 고기 전문점
4. 기타 (일식, 중식 등)
