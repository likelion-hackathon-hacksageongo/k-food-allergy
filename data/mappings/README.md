# 매핑표

## `allergen_map.csv` — 공공 데이터 19종 → 우리 16종

식약처 알레르기 유발물질 표시 대상과 [`profiles/models.py`](../../backend/profiles/models.py)
의 `AllergenChoice` 16종은 목록이 다릅니다. 19종이 16종으로 **그룹화**되며 매핑됩니다.

```
게 + 새우          → shellfish
호두 + 잣          → nuts
오징어 + 조개류    → mollusk
나머지 13종        → 1:1
```

### 알려진 손실

- **게 / 새우 구분 소실** — 실제로 갑각류 알레르기는 종별로 반응이 다를 수 있으나
  현재 스키마는 `shellfish` 하나로만 표현합니다.
- **어류가 `fish` 하나** — 공공 표시 대상은 고등어만 지정하지만, 실제 한식에는
  멸치·명태·황태가 훨씬 자주 쓰입니다. 전부 `fish` 로 넣습니다.

### ⚠️ 미커버 알레르겐: 참깨(sesame)

`AllergenChoice` 16종에 **참깨가 없습니다.** 그런데

- 참기름·통깨는 거의 모든 한식 반찬과 무침에 들어갑니다
- 참깨는 미국·EU에서 표시 의무 알레르겐입니다

외국인 대상 서비스에서 이건 실제 공백입니다. `AllergenChoice` 에 `sesame` 추가를
팀에 제안해야 합니다. 추가 전까지 참깨 함유 재료는 `notes` 에만 기록됩니다.

### 갱신 시 주의

표시 대상 목록은 개정될 수 있습니다. 데이터 수집 시점의 현행 고시를 확인하고,
변경이 있으면 이 표와 위 손실 목록을 함께 갱신하세요.
